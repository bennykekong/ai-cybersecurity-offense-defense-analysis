
# AI for Cybersecurity: Offense & Defense Analysis

**Project completed:** 2025  
**Published to GitHub portfolio:** 2026  
**Assessment result:** 30/30

## 🔎 Project Overview

This project evaluates how three generative AI platforms respond to cybersecurity-related prompts across offensive and defensive security scenarios.

The analysis compared:

- ChatGPT
- Google Gemini
- Microsoft Copilot

The project examined whether the models would generate potentially harmful cyber content, whether they applied safeguards or disclaimers, and how effectively they supported defensive-security analysis.

---

## 🎯 Project Objectives

- Compare AI responses to offensive-security prompts
- Evaluate AI safety safeguards
- Observe whether models refuse harmful requests
- Compare response behavior across multiple AI platforms
- Assess AI effectiveness for defensive cybersecurity analysis
- Analyze Windows Firewall logs using AI
- Analyze potentially malicious Python code using AI
- Evaluate whether AI provides recommended next steps
- Examine the potential role of AI alongside traditional security tools

## 🚫 Offensive-Security Safeguard Analysis

The assessment tested how the AI platforms responded to requests involving potentially harmful cybersecurity activities.

The scenarios included requests related to:

- Phishing-email generation
- Keylogger code
- SQL-injection code
- Security-training variations of those prompts

Across the tested scenarios, the three AI systems did not directly provide the requested harmful email or code and instead applied safeguards, warnings or refusals.

This demonstrated the role of AI safety mechanisms in limiting direct support for malicious cyber activity.

## 📊 Comparative Findings

The project demonstrated two different AI-security behaviors:

### Offensive Requests

The tested AI platforms consistently applied safeguards when prompted to generate content associated with phishing, keylogging and SQL-injection attacks.

### Defensive Requests

The same platforms were more useful when asked to:

- Analyze suspicious logs
- Identify potentially malicious behavior
- Examine suspicious code
- Recommend investigation steps

This showed that generative AI can provide more practical value when used as a defensive-analysis assistant rather than as a tool for generating offensive cyber content.

---

## 🔗 AI + Traditional Security Tools

The project concluded that AI can potentially complement security tools such as firewalls by helping analysts:

- Interpret security logs
- Identify suspicious patterns
- Analyze potentially malicious code
- Summarize findings
- Recommend further investigation steps

AI should support, rather than replace, traditional security controls and analyst judgment.

## 📈 Key Takeaways

This project strengthened my understanding of both the opportunities and limitations of generative AI in cybersecurity.

The analysis demonstrated that major AI platforms apply safeguards against directly generating potentially harmful cyber content while remaining useful for defensive tasks such as log analysis and suspicious-code assessment.

The project also highlighted the value of combining AI-assisted analysis with established cybersecurity tools and human security judgment.
